# 1. Setup

## 1.1) Install Python
	https://www.python.org/downloads/

## 1.2) Install required modules
	`pip install matplotlib`
	`pip install requests`
	`pip install pandas`
	`pip install numpy`

# 2. Update counts
The data.csv file should be placed in the same directory as the python scripts.
	1. open a command prompt
	2. run the script `python getCompetitorCounts.py`
	3. New counts should be appended to data.csv

# 3. View results

	1. run the chart script `python chartit7.py`
